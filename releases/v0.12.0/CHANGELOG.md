# AgentDeck v0.12.0

发布日期：2026-10-22。平台：Windows x64。版本资源：ProductVersion `0.12.0`，FileVersion / 应用清单 `0.12.0.0`。

本版集中改进删除与整理会话时的体验和性能：删除对话框重新设计，删除前是否备份改为设置项；
本地会话库可以清理累积的历史版本；收藏、归档等整理操作不再重新载入整个列表，并提供撤销。

## 新增

- **删除前备份改为设置项**：新增「设置 → 会话 → 删除会话 → 删除前创建恢复备份」，默认开启。
  - 开启时删除前先写恢复备份，删除后提示条提供「撤销删除」，对话框不要求额外勾选。
  - 关闭时删除全部成功后即丢弃备份、不提供撤销；对话框以醒目样式说明「删除后无法恢复」，
    必须勾选「我了解此操作无法撤销」才能删除。
  - 关闭备份**不是跳过备份**：恢复备份仍然先写、先校验，删除中途失败时的自动回滚依赖它；
    只在全部删除成功后逐个删除备份文件（目录只以非递归方式收掉），保留只含会话标识的
    `operation.json`，防止已删会话被其他来源重新收录（后端 `DeleteSessionsPermanently`、
    `NativeDeletePlan.DiscardBackup`）。
- **清理历史版本**：「设置 → 数据管理 → 本地会话库 → 清理旧版本…」按「每个会话保留最新 N 个
  版本」（默认 5）先预览将清理的版本数、涉及会话数与可释放空间，勾选确认后执行。每个会话当前
  使用的版本始终保留；候选集计算与删除在同一事务内完成，之后 `VACUUM` 回收文件空间。
  本机 1.8 GB 的会话库中，1.2 GB 来自同一个活跃会话的 285 个版本。
- **整理操作的反馈与撤销**：归档、取消归档、批量收藏等成功后提示完成数量并提供「撤销」；批量
  操作部分失败时单独说明失败数量，撤销失败也会提示。
- **首次扫描进度**：扫描本机会话时显示「已处理 N / M 个文件」。
- **加载失败可重试**：会话列表加载失败时提供「重试」按钮。
- **空列表引导**：没有会话时提供「新建会话」入口与排查提示。

## 改进

- **删除对话框重新设计**：问句标题（「要删除此会话吗？」）、一句话说明后果、条目列表（超过 5 个
  时折叠为「以及另外 N 个会话」），只保留「取消」与「删除」两个按钮；文件数、大小、路径等核对
  细节默认折叠；没有已知子会话时不显示「同时删除子会话」。
- **标注写入改为局部更新**：收藏、归档、标签、备注、改名后，前端把 60 ms 内的变更合并成一轮
  `Get(key)`，只把这五个字段并入已有的行（`markPatch.applyMarkPatch`）；只有当有会话新进入当前
  范围而列表中没有它时，才退回整表重载。批量操作由 N 次整表重载降为一轮请求。
- **新建项目只刷新侧栏**：新增 `projects:changed` 事件，不再重载会话列表。
- **Codex 改名去重**：恢复 Codex 会话前，若其 `session_index.jsonl` 中已是同名，就不再冷启动
  app-server（此前每次恢复都要等待数秒，最长 20 秒）。
- **终端默认选用最高版本的 PowerShell**：默认值由 Windows PowerShell 5.1 改为「自动」（优先
  PowerShell 7+）。已显式保存的选择不受影响。
- **长列表渲染**：屏幕外的会话行使用 `content-visibility: auto`，不参与布局与绘制；行仍在 DOM 中，
  焦点、查找与 `scrollIntoView` 不受影响。
- 删除、整理与清理旧版本相关的界面文案统一为规范写法。

## 修复

- 行内收藏与「取消归档」失败时错误被静默吞掉，现在会弹出错误提示。
- 设置搜索「清理旧版本」没有结果：本地会话库一节补充了对应关键词。
- 不保留备份的删除若未能清理干净临时备份，提示条不再误称「可以撤销」。

## 性能测量

新增基准 `internal/app/perf_bench_test.go`（合成数据，i7-13700H）：

- 一次标注写入加上 `List`、`Get`、`Agents`、`Projects`、`Counts` 的完整刷新：700 条约 3.5 ms，
  2100 条约 6.0 ms。`List` 单次约 0.9 ms，列表 JSON 载荷约 375 KB。
- 结论：瓶颈在列表载荷的跨桥序列化与前端重渲染，而不是后端计算，因此本版的优化放在前端，
  未增加后端缓存。
- 会话解析结果已持久化在 `cache/sessions.json`，命令行暖启动实测 0.44～1.13 s；首次或缓存失效时
  的十几秒是一次性重建。

## 安装与升级

1. 下载 `AgentDeck-v0.12.0-win-x64.exe`，或包含程序与许可说明的 `AgentDeck-v0.12.0-win-x64.zip`；
   用 `SHA256SUMS` 校验下载文件。
2. 退出旧程序后，将新 EXE 放到固定位置并启动。已有数据与偏好继续使用；升级前可在「备份与恢复」
   创建完整备份。
3. 若移动了 EXE 且启用了开机启动，在新程序中关闭并重新启用该选项以更新路径。
4. 「删除前创建恢复备份」默认开启，升级后删除行为与 v0.11.0 相同（先备份、可撤销）。
5. 终端设置为空的用户升级后改用「自动」；已显式选择 5.1、7+ 或自定义路径的保持不变。
