# AgentDeck v0.19.2

发布日期：2026-11-13

## Changed

- 设置里的“关于与更新”改名为“关于”，两块内容合并成一页，并去掉重复信息：版本号只在“版本与更新”里显示一次（此前“关于”里还有一行“版本”）；许可证只写一处，原来 MIT 在许可证一行和下面的说明里各写一遍；去掉了页面标题之外多余的“关于 AgentDeck”小标题。
- 隐私与数据说明移到更新之后，因为它说明的唯一对外请求就是“检查更新”；并改掉其中已不存在的“在更新设置中关闭”的说法，现在是“可在上方关闭启动后的自动检查”。
- 页面顺序：产品信息（开发者、源码仓库、许可证）→ 版本与更新 → 隐私与数据。
- 设置搜索仍能搜到原来的内容；搜索结果的标题前缀由“关于与更新 · …”改为“关于 · …”。
- README 中两处“设置>关于与更新”同步为“设置>关于”。

## 说明

- 本版只有上面的界面调整，没有改动 Go 代码、数据格式或配置字段，也没有修复缺陷。按版本规范（`0.x.y` 只用于修复缺陷）它本应是 v0.20.0；这里按维护者的指定使用 v0.19.2（与 v0.18.1 的做法相同）。

## Known Issues

- 与 v0.19.1 相同：原始会话里已经变成 `�` 的内容无法恢复；恢复误删会话时账号名称要与当初导入时一致；推荐的项目名只是推测；“在 ChatGPT 中打开”的网址格式未逐项验证；浏览器检测与启动仅支持 Windows。
- 与 v0.17.0 相同：导出里图片文件名多为通用名、阅读区图片暂不支持点击放大、旧版导出的 Markdown 不被识别为同一会话、含大量图片的备份旧版（4 GiB 上限）无法恢复。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 本版只改前端界面，不改数据库结构与配置字段，首次启动无需迁移。
- 升级：在应用内“检查更新”，或用新 exe 手动替换。
- 回退：换回上一版 exe 即可，数据与配置不受影响。
