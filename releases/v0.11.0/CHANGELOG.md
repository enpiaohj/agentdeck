# AgentDeck v0.11.0

发布日期：2026-10-22。平台：Windows x64。版本资源：ProductVersion `0.11.0`，FileVersion / 应用清单 `0.11.0.0`。

本版把三栏宽度全部做成可拖动：会话列表与会话详情栏此前是固定宽度，会话标题一长就只能看到省略号；
现在拖一下分隔条就能临时放宽，看完再双击回到自动宽度。

## 新增

- **会话列表可拖动改宽**：列表右侧新增分隔条。拖动调整宽度，双击恢复自动宽度；聚焦分隔条后
  方向键按 8px、Shift+方向键按 32px 微调。长标题不再只能看省略号。
- **会话详情栏可拖动改宽**：详情栏左侧新增分隔条，交互与列表一致，写备注、看长标题时更好用。
- **宽度会被记住**：三栏宽度各自存入本机偏好，重启后保持；与原有的侧栏宽度共用同一套规则。
- **设置 → 外观 → 界面布局**新增「会话列表宽度」「会话详情栏宽度」两行，显示当前像素值并提供
  「恢复自动宽度」；设置搜索新增对应关键词，快捷键页新增「调整栏宽」。

## 改进与修复

- **三栏共用一套拖动实现**：抽出 `usePaneResizer` 与 `PaneResizer`，导航、列表、详情不再各写一份；
  拖动期间只更新本地预览，松手才写入偏好。
- **宽度三重约束**：每一栏同时受「该栏上下限」「窗口宽度份额」「窗口宽度 − 另两栏实际宽度 −
  阅读区下限 320px」约束，任何一栏拉到最宽也不会把正文区挤没；窗口变窄时已保存的宽度自动收。
- **分隔条不再画强调色竖线**：悬停、拖动、聚焦都不画整条线，只靠光标形状提示可拖；纯键盘操作时
  在竖直中部显示一个小圆点，焦点仍然可见。
- **修复双击复位不生效**：分隔条在 `pointerdown` 上调用 `preventDefault()`（避免拖动时选中正文），
  Chromium 因此吞掉兼容鼠标事件，`onDoubleClick` 根本不触发。改为在 `pointerdown` 里自行判断连击。
- **修复单击即固定宽度**：此前松手无条件写入偏好，只点一下不拖动也会把「跟随布局默认」悄悄变成
  固定像素值。现在只有真正拖动过才写入。
- **修复键盘微调拿不到焦点**：`pointerdown` 的 `preventDefault()` 同样拦住了默认聚焦，点击后按方向键
  没有反应；现在在按下时显式聚焦分隔条。
- **删除会话不再整库备份，改为按会话备份**：此前每次删除都把整个会话库 `VACUUM INTO` 一份再全量校验，
  本机 1.7 GB 的库实测 **43 秒**（`VACUUM INTO` 3.3 秒 + 校验 39.9 秒），而真正要留住的只是所选会话的
  那几行。现在 `history.BackupKeysTo` / `marks.BackupKeysTo` 只复制所选会话的保留版本与标注，
  同一次删除实测 **41 毫秒**；备份库结构与主库一致，撤销删除与失败自动回滚两条路径不变。
  需要整库备份时仍可用「设置 → 备份与恢复 → 创建完整备份」手动触发。

## 安装与升级

1. 下载 Windows x64 EXE，或包含程序与许可说明的分发 ZIP；用 `SHA256SUMS` 校验下载文件。
2. 退出旧程序后，将新 EXE 放到固定位置并启动。已有 AgentDeck 数据与偏好继续使用；升级前可在
   「备份与恢复」创建完整备份。
3. 若移动了 EXE 且启用了开机启动，在新程序中关闭并重新启用该选项以更新路径。
4. 已有的宽度偏好保持不变；三栏宽度默认仍是「随窗口自动调整」，拖动后才会固定。
