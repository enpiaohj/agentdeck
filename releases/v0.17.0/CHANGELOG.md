# AgentDeck v0.17.0

发布日期：2026-11-12

## Added

- **导入 ChatGPT 网页版聊天记录**：顶部“导入”里新增 ChatGPT 页，读取官方“设置”>“数据控制”>“导出数据”得到的
  ZIP（或其中的 `conversations-*.json`）。全程只读，不登录、不读取任何账号凭据；导出文件不会被改动。
  - 沿 `current_node` 还原你看到的那条分支；保存对话文本、语音转录与思考摘要，清理文本里的引用标记。
  - ChatGPT 项目（Projects）里的会话按项目分组。官方导出里**没有项目名**，只有 `g-p-` 开头的项目编号，所以导入时
    列出各项目最近的会话标题供你命名；留空则显示为“ChatGPT 项目 xxxxxx”，之后可重命名，不必重新导入。
  - 你上传的文件（文档、代码、表格等）不复制，只在对话里保留文件名、类型与大小；语音对话的导出里本来就没有音频文件，
    只有文字转录。
  - 导入页有“同时导入图片”复选框（默认选中，并显示约占空间与张数）：图片按内容哈希去重存放，在阅读区直接显示，
    并入同一条消息；图片带着上传时的文件名作替代文字（没有导入图片时占位符里也写文件名）。
  - 导入的记录与 Claude 导入一样只读：可查看、全文搜索、收藏、加标签与备注、导出 Markdown；不能恢复为命令行会话，
    也不能删除原始记录。
  - 存放在导入目录之下（磁盘上是 `imports/claude/chatgpt/`，图片在各账号的 `assets/` 里），随完整备份与数据迁移一起走。

## Changed

- **Markdown 导出文件名**改为 `日期-会话标题-短ID.md`：日期取会话开始日期，标题已清理 Windows 非法字符并限长，
  短 ID 是会话 ID 前 8 位。重复导出同一会话得到同一个文件；会话改名后，按文件头里的 `session_id` 认出旧文件并改名，
  不另存一份，也不覆盖别人的同名文件（占用时加 `_2`、`_3`）。
- **Markdown 导出排版**面向长期阅读与归档：YAML front matter（会话 ID、智能体、项目、起止时间、模型、标签、备注）、
  中文标签、用户轮次序号与分隔线、轮次多时先给“对话概览”、工具调用折叠成“工具名 · 关键参数”一行；导出的图片复制到
  导出目录的 `assets/` 并改为相对路径；先写临时文件再改名，写到一半失败不会毁掉旧导出。
- **完整备份的上限**由 4 GiB / 2 万个文件放宽到 16 GiB / 10 万个文件（带图片导入后，永久库加导入库容易超过原先的上限）。
  上限仍在，用于防止损坏或恶意的备份包撑爆磁盘与内存。
- **界面用语**向微软简体中文本地化风格对齐：“搜索”（取代“检索”）、“复制”“命名”“重命名”“占位符”“转录”；引号统一为“”，
  菜单路径写作“设置”>“数据控制”；错误信息改为“发生了什么 + 怎么办”，不再带“整批”“清单”等内部说法或英文底层报错。
  全角冒号、“账号”“智能体”等沿用原写法。
- 个别导入批次损坏时，只跳过受影响的部分，该来源的其余会话照常显示，并提示缺了什么（此前一个批次损坏会让该账号的
  全部 ChatGPT 会话消失）。同一会话、同样新的两份导入，带图片的那份优先显示。

## Security

- 升级 `klauspost/compress` 到 v1.20.2（GO-2026-6865：zstd 在两块帧上 panic，永久库的正文压缩走这条路径）。
- Go 工具链升到 go1.27.4（GO-2026-6859：标准库 net/http 的 MaxBytesReader 头部竞争）。
- 发布前 `govulncheck@v1.1.4` 与 `npm audit` 均为 0 项（升级前 govulncheck 报告上述两项）。
- ChatGPT 图片只通过一个严格限定的地址形态提供（账号目录与内容哈希各 64 位十六进制、固定扩展名），只读该账号自己的
  `assets/` 目录，附 `Content-Security-Policy`、`Cross-Origin-Resource-Policy` 与 `nosniff` 头；越界路径、未存储的哈希、
  非 GET/HEAD 请求一律 404，并有单测覆盖。

## Fixed

- 搜索结果的摘要里不再出现图片地址：图片是独立的“图片”段落，全文索引不收它，也不会被搜到，提问计数不受影响。
- 导入前检查磁盘空间，空间不足时给出明确提示，而不是复制到一半失败；清理上次中断留下的暂存目录与图片临时文件。
- 异常输入：超出合理范围的时间戳视为“未知”，标题限长，只由点组成的项目名不会变成路径（`.`、`..`），
  ZIP 内文件数超过 20 万的直接拒绝。

## Known Issues

- 官方导出不含项目名，只能由你命名；导出里图片文件名多为通用名，占位符与替代文字价值有限。
- 预览显示的图片数量与大小按导出里的文件计，内容相同的图片只存一份，实际占用略小。
- 阅读区的图片暂不支持点击放大。
- 中途复制图片失败时，该次导入整批不生效，但已复制的图片会留在存储里，下次导入时复用。
- 旧版本导出的 Markdown（旧文件名格式）不会被新版认作同一会话的导出，会各存一份；需要时自行清理。
- 带图片导入后，完整备份会明显变大；本机永久库已有数 GB 时，备份耗时也会相应增加。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 0.x 阶段不承诺配置与数据完全兼容。本版只新增数据（导入目录下的 `chatgpt/`），不改写已有数据库结构。
- 升级：在应用内“检查更新”或手动用新 exe 替换即可；首次启动不需要迁移。
- 回退：换回上一版 exe 即可。ChatGPT 的导入数据留在原处，旧版不读取、不删除；之后再升级会自动重新显示。
- 旧版创建的完整备份可在本版恢复；本版创建的备份若含 ChatGPT 图片，体积可能超过旧版的 4 GiB 校验上限，
  旧版恢复会拒绝，请用本版或更新的版本恢复。
