# AgentDeck v0.20.2

发布日期：2026-11-18

## Changed

- 按微软中文术语与风格检查并统一其余页面的文字（共 152 处、36 个文件）。
  - 明显不规范的写法：“重启”改为“重新启动”（如“立即重新启动”），“托盘”改为“通知区域”（如“关闭时最小化到通知区域”），“开机启动”改为“登录时启动”，“勾选”改为“选中”，“拖拽”改为“拖动”，“读不了”改为“无法读取”。
  - 微软有固定写法的术语：“撤销”改为“撤消”（如“撤消删除”）；备份与删除相关的“恢复”改为“还原”（如“备份与还原”“从完整备份还原…”“还原备份”“还原误删的会话”“还原偏好设置”）。
  - 后端的错误提示同步修改（删除与还原备份、数据迁移、桌面设置、更新等）。
- 保持不变：表示“继续会话”的“恢复”（如“复制恢复命令”“原生恢复”“跨目录恢复”“命令行恢复”）；“置顶”“归档”“目录”“偏好设置”等产品功能名与术语。
- 设置搜索里保留了旧叫法的关键词（如“托盘”“开机启动”“恢复备份”“撤销”“重启”“拖拽”），仍能搜到对应设置。
- README 同步修改，“启动与系统托盘”一节改名为“启动与通知区域”。

## 说明

- 本版只有上面的文字调整，没有改动功能、数据格式或配置字段，也没有修复缺陷。按版本规范（`0.x.y` 只用于修复缺陷）它本应是 v0.21.0；这里按维护者的指定使用 v0.20.2。

## Known Issues

- **构建工具链有一项尚无修复版本的高危公告（与 v0.20.1 相同的例外，沿用维护者的确认）**：`npm audit` 报告 `picomatch`（`<=4.0.7`，ReDoS，GHSA-fc5q-39xc-vjpf）经 `vite` → `fdir` / `tinyglobby` 传导，共 4 项高危。发布时重新核对：npm 上 `picomatch` 的最新版本仍是 4.0.7，没有修复版本；npm 建议的把 `vite` 降到 6.2.7 本身带有另一个高危公告，不能消除问题。影响范围：只有开发时的前端构建工具（`devDependencies`），不是运行时依赖；`npm audit --omit=dev`（生产依赖）为 0 项；发布的 exe 和前端产物里都不含 `picomatch`。上游一发布修复版本就升级。
- 设置页左下角的“偏好设置仅应用于当前设备”和“还原偏好设置？”里的“偏好设置”未改（微软对应的“首选项”不在本次范围）。
- 重建的会话不是原文件：工具调用的 id 配对、思考内容、消息 id 无法还原；只支持 Claude Code。
- 与 v0.20.0 相同：会话保留期的“到期”按文件修改时间和默认 30 天估算；原始会话里已经变成 `�` 的内容无法恢复；仅 Windows。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 本版只改界面文字，不改数据库结构与配置字段，首次启动无需迁移。
- 升级：在应用内“检查更新”，或用新 exe 手动替换。
- 回退：换回上一版 exe 即可，数据与配置不受影响。
