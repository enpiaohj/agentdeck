# AgentDeck v0.2.0

发布日期：2026-10-17。平台：Windows x64。此版本新增本地永久历史与完整数据备份，并完善桌面工作台、阅读体验和设置。

## 新增

- 永久会话库：成功读取的完整解析正文与元数据默认持久保存，无自动过期；相同正文去重，变化保留版本。原记录删除后，已保存副本仍可阅读、检索、标注和导出。
- 完整数据备份与恢复：ZIP 包含永久历史全部版本、收藏、归档、标签、备注、Claude 导入库及界面偏好；支持清单、路径、SHA256 和数据库校验。恢复前自动备份当前数据，合并后刷新列表、正文并重建全文索引。
- Claude 官方 JSON / ZIP 聊天历史导入，按账号名称区分，重复导入去重并合并更新批次。
- Ctrl / Shift 桌面式多选、Ctrl+A 全选当前筛选结果、键盘导航、右键菜单及 Markdown 批量导出。
- 分组设置与搜索，支持主题、字号、行距、阅读宽度、默认定位和过程折叠偏好，即时保存并提供阅读预览。

## 改进

- 默认四栏工作台及展开的会话详情，各栏可收起；调整信息密度、控件边界、排版层次、留白和焦点反馈。
- 顶部全文搜索改为内联结果，支持方向键、中文输入、跨页定位及过期请求隔离。
- 正文默认定位最新问答，提供开头 / 最新消息和连续分页；超长输出明确提示截断并可展示末尾。
- 思考、工具输出、上下文、大段 JSON 及长代码默认折叠，完善 Markdown / GFM 排版、代码高亮、复制及搜索命中展开。
- 新增活动月份与账号筛选，完善历史分组、即时刷新、排序和存储状态反馈。
- 更新立体应用图标及 Agent 品牌图标，保留来源与许可证；左上角显示应用版本，统一专业界面用语。
- 设置使用独立分类侧栏和返回入口，完善窄窗口布局及快捷键。

## 修复

- 标题栏品牌及空白拖拽区域双击最大化 / 还原，搜索框与按钮保留各自交互。
- 刷新重新扫描磁盘并同步会话正文与统计，索引按扫描代次更新并处理排队请求。
- 补扫 Claude Desktop 本地目录，依据明确的 Desktop 元数据识别共享 CLI 记录，保留已有标注。
- 修复 Windows 文件替换期间短暂缺失的读取重试，补充确定性回归测试。
- 桌面服务测试使用独立内存索引与用户目录隔离，避免读取或改写真实用户索引。
- 前端共用资源同步脚本，复制新资源前移除旧 bundle；拆分依赖，消除大主包提示。
- 右键操作及数据恢复后同步标签、备注、收藏、归档和详情显示。

## 安装与升级

1. 关闭旧版 AgentDeck，建议先备份 `%APPDATA%\AgentDeck` 与 `%LOCALAPPDATA%\AgentDeck` 数据目录。
2. 运行 `AgentDeck-v0.2.0-win-x64.exe`，需要 Windows WebView2 Runtime；原有数据路径继续使用。
3. 升级后可在“设置”中创建完整数据备份。首次建立索引或保存历史时需要等待后台处理完成。

备份仅包含 AgentDeck 自有数据及界面偏好，不包含原生 Agent 目录、凭据和可重建全文索引。恢复保留已有历史版本，同名标注采用备份内容，导入冲突不覆盖；各数据库分别事务合并，不提供跨库原子事务。异常时可使用程序提示的恢复前自动备份继续恢复，默认保存在 `%LOCALAPPDATA%\AgentDeck\library\data-recovery`。

## 已知限制

- Claude 云端聊天不自动同步；需要导入官方导出文件，附件本体、图片及部分工具内容不在导入范围。
- 永久保存从成功读取开始；尚未读取且已被上游删除的记录无法补回。永久副本不支持继续原生会话。
- 完整备份上限为解压后 4 GiB、20,000 个数据文件。
- 本版本提供未签名的独立 EXE，无安装包。
- 历史版本记录的 `TestIncremental`、`TestWSLOmpProfiles` 偶发失败本次未复现，尚不能认定根因已解决。
- 本机未配置 Git 远端，Push 与 GitHub Release 未执行。
