# AgentDeck v0.18.1

发布日期：2026-11-12

## Changed

- 设置里的“更新”和“关于”两个分类合并为“关于与更新”：一页里先是“版本与更新”（检查更新、自动检查开关、版本信息、发布页），
  下面是“关于 AgentDeck”（开发者、源码仓库、许可证、第三方组件、隐私与数据说明）。设置栏少一项，也少点一次。
- 设置搜索仍能搜到原来两部分的内容，结果标题改叫“关于与更新 · …”。
- README 中“设置>更新”的写法同步为“设置>关于与更新”。

## 说明

- 本版只有上面这处界面调整，没有改动 Go 代码、数据格式或配置字段，也没有修复缺陷。按版本规范（`0.x.y` 只用于修复缺陷）它本应是
  v0.19.0；这里按维护者的指定使用 v0.18.1。

## Known Issues

- 与 v0.18.0 相同：推荐名只是推测；浏览器检测只是提示，识别不了浏览器配置文件；“在 ChatGPT 中打开”的网址格式来自第三方资料，
  尚未在账号上逐项验证；浏览器检测与启动仅支持 Windows。
- 与 v0.17.0 相同：导出里图片文件名多为通用名、阅读区图片暂不支持点击放大、旧版导出的 Markdown 不被识别为同一会话、
  含大量图片的备份旧版（4 GiB 上限）无法恢复。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 本版只改前端界面，不改数据库结构与配置字段，首次启动无需迁移。
- 升级：在应用内“检查更新”或手动用新 exe 替换即可。
- 回退：换回上一版 exe 即可，数据与配置不受影响。
