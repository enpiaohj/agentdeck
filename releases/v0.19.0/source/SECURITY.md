# Security Policy

## 支持的版本

只维护最新发布版本。旧版本不再接收修复。

| 版本 | 支持 |
| --- | --- |
| 最新 `vX.Y.Z` | ✅ |
| 更早版本 | ❌ |

## 报告漏洞

请**不要**用公开 Issue 报告安全问题。任选其一：

- 用 GitHub 的 [Private vulnerability reporting](https://github.com/enpiaohj/agentdeck/security/advisories/new)；
- 或发邮件到仓库维护者的 GitHub 联系邮箱。

请在报告中说明：受影响的版本、复现步骤、影响范围，以及你认为的严重程度。
**不要**在报告里附带真实的会话正文、账号凭据或个人数据；需要样本时请用脱敏后的
最小复现。

## 处理流程

1. 收到后 7 天内确认并给出初步判断。
2. 修复随下一个 PATCH 版本发布，并在 CHANGELOG 中说明。
3. 修复发布后再公开细节；如果你希望署名，请在报告中注明。

## 依赖与构建

- 每次发布前运行 `govulncheck` 与 `npm audit`，两者都为 0 项才发布；Dependabot 持续监控依赖告警。
- `go.mod` 用 `toolchain` 固定构建所用的 Go 版本，标准库漏洞通过升级该版本修复。
- `releases/vX.Y.Z/source/` 是不可变的发布快照，其中依赖清单上的告警会被驳回，不代表当前代码
  仍受影响；当前代码的依赖告警通过 PATCH 版本修复。

## 范围

AgentDeck 会在本机读取第三方 Agent 的会话存储，并在用户显式发起时删除会话。
以下属于安全范围：

- 恢复命令构造中的参数注入或路径穿越（`session-id`、`cwd`）。
- 手动删除路径的越权写入、绕过预览确认、备份失败仍删除、删除目录；关闭「删除前创建恢复备份」
  时，在删除完成之前丢弃备份，或丢弃了不属于本次删除的文件。
- 脱敏失效导致日志、诊断包或导出文件泄露凭据。
- 迁移与备份恢复中的数据损坏或路径逃逸。

以下不在范围：

- 需要本机管理员权限或已完全控制用户账户的攻击。
- 第三方 Agent 自身的安全问题。
- 未签名产物触发的 SmartScreen 提示（已知限制，见 README）。
