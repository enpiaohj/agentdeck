# AgentDeck v0.19.0

发布日期：2026-11-12

## Added

- **恢复误删的会话**：导入 ChatGPT 导出时，预览会列出“这份导出里你之前从 AgentDeck 删除过的会话”（标题、最近更新日期，最多 1000 条，按更新时间从新到旧），每条一个复选框，默认都不选，带“全选 / 全不选”和已选计数。只有勾选的会重新导入，其余保持删除。恢复的是新导入的副本，原来的收藏、标签和备注不会回来。恢复后可以再次删除。
- **删除导入的聊天记录**（默认关闭）：“设置”>“会话”里开启“允许删除导入的聊天记录”后，导入的 ChatGPT 会话可在会话详情、右键菜单和批量选择里删除。只删 AgentDeck 里的副本（含每个批次里的全部副本、保留的版本、收藏、标签、备注），不影响 ChatGPT 上的原始聊天与导出文件。沿用现有删除流程（预览确认、先写并校验恢复备份、失败回滚、本次运行内可撤销）；服务端在预览和执行时各检查一次开关；Claude 等其他导入记录仍不支持删除。
- 账号名称与已有账号不一致但内容重叠时，导入页提示“这份导出里有 N 个会话已在账号‘X’下导入过”，并给出“改用‘X’”按钮；名称一致时说明有多少已导入的会话不在这份导出里。

## Changed

- 已删除的会话重新导入时不再写回磁盘（此前内容会被写回，只是界面上隐藏）。全部是已删除会话的导出不再报错，而是提示“没有新的内容”。
- 导入后自动清理被取代的旧批次（只删清单里列出的转录文件和清单本身，文件夹为空才删，读不了的批次不碰），结果里写明释放了多少空间。
- 某个会话在旧批次里缺文件，但别的批次里还有它的副本且能正常显示时，不再当作问题报告。
- 项目名输入框清空后会清掉已保存的名字（回到默认名称）。
- 导入服务接口 `ImportChatGPT` 增加 `restore` 参数，预览结果增加 `deleted` 列表（前端绑定已同步生成）。

## Known Issues

- 与 v0.18.x 相同：推荐名只是推测；浏览器检测只是提示；“在 ChatGPT 中打开”的网址格式来自第三方资料，尚未在账号上逐项验证；浏览器检测与启动仅支持 Windows。
- 与 v0.17.0 相同：导出里图片文件名多为通用名、阅读区图片暂不支持点击放大、旧版导出的 Markdown 不被识别为同一会话、含大量图片的备份旧版（4 GiB 上限）无法恢复。
- “恢复误删的会话”按账号名称计算会话 ID：恢复时账号名称要与当初导入时一致（忽略大小写），否则预览里看不到已删除的会话。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 不改数据库结构与配置字段；新增的 `allow_import_delete` 配置项默认 `false`，旧配置文件无需修改。
- 升级：在应用内“检查更新”，或用新 exe 手动替换。
- 回退：换回上一版 exe 即可。恢复会话时会改写 `deletions/` 下对应记录（去掉被恢复的 key、全部去掉后状态改为 restored）；回退到旧版后这些会话按旧逻辑显示，数据不受影响。
