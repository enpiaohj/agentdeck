# AgentDeck v0.8.0

发布日期：2026-10-21。平台：Windows x64。新增开机启动与系统托盘，重组设置分类，并修复小窗口菜单及终端设置交互。

## 新增

- 「设置 → 常规 → 启动与退出」新增开机启动和关闭时最小化到托盘，两个选项独立保存、默认关闭。登录启动隐藏主窗口，手动启动仍显示窗口。
- 托盘提供「打开 AgentDeck」和「退出」。隐藏后再次手动打开程序会恢复已有窗口；显式退出和数据迁移重启绕过关闭到托盘。
- 配置保存失败会回退自启动状态；加载、保存、失败回读及重试均显示实际结果。配置保留既有数据位置、终端配置及未知字段。

## 调整

- 设置统一为常规、外观、会话、终端、数据管理、备份与恢复、诊断、快捷键八个分类，16 个设置控件均保留。
- 字号、行距和阅读宽度集中到「会话」，侧栏及详情栏归入「外观」。数据位置和本地会话库、完整备份、智能体检测及搜索索引按用途分别展示。
- 设置项采用统一的标题、说明与控件布局；统一分组名称和标题层级。恢复偏好设置需确认，并明确保留启动、托盘、终端配置和会话数据。
- 设置搜索支持多个关键词、全角与大小写归一化，并包含 PowerShell 版本和深色主题等实际选项名称。

## 修复

- 修复小窗口右键菜单底部裁切及 Fluent 默认样式覆盖菜单宽度。菜单限制在视口内，高度不足时滚动，键盘焦点自动进入可见区域。
- 修复选择自定义 PowerShell 后不显示路径输入框。保存失败等待实际状态回读后再解除禁用；初始读取失败可重试。

## 升级与使用

- 退出旧版后，解压分发 ZIP 或运行 `AgentDeck-v0.8.0-win-x64.exe`。继续使用现有数据目录，不自动清理会话，不引入数据库结构迁移。
- 开机启动使用当前用户的 Windows 启动注册项，记录启用时的 EXE 绝对路径。建议先放到固定目录再启用；移动或更换 EXE 路径后，在新程序中关闭并重新开启该选项以更新路径。
- 两个桌面选项保存在 `%APPDATA%\AgentDeck\app-config.json`；旧配置缺少字段时默认关闭。界面偏好的原有保存方式不变。
- 独立 EXE 需要 Windows WebView2 Runtime。本版本未进行代码签名。
