# AgentDeck v0.2.1

发布日期：2026-10-17。平台：Windows x64。此修复版本解决 Codex 主会话与子 Agent 记录平铺显示，造成会话数量偏多的问题。

## 修复与改进

- 根据已确认的根会话关系，将 Codex 子 Agent 记录收在所属主会话下，默认折叠；支持点击或左右方向键展开 / 收起，嵌套子 Agent 归入同一根会话。
- 列表区分主会话和子会话数量，智能体与项目统计不重复计入可归组的子会话，展开后显示缩进与“子会话”标识。
- 保留所有原始记录、正文、独立收藏、标签、备注和归档。父会话缺失或被筛选时，子会话仍可单独访问；未知身份保持独立，不按标题或项目猜测归并。
- 主会话活动时间包含子会话更新，启动优先选中所属主会话；按实际时间比较，兼容不同时区。
- 全文搜索命中子会话后，返回列表自动展开所属主会话并保留选中高亮；筛选、右键操作和 Ctrl / Shift 多选继续可用，折叠时全选仅包含可见行。
- 会话详情明确显示子 Agent 类型；从当前子会话收起列表时切换回主会话，避免详情与列表脱节。

## 升级

关闭旧程序，运行 `AgentDeck-v0.2.1-win-x64.exe`。沿用现有本地数据目录，无数据库迁移或数据清理；建议升级前在“设置”中创建完整备份。

本次只改变展示和统计，不把子 Agent 正文拼入主会话，也不合并不同主会话 ID。原有版本、快照及产物保持不变。程序需要 Windows WebView2 Runtime。
