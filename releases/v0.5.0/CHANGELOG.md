# AgentDeck v0.5.0

发布日期：2026-10-19

## Added

- **新建项目可选择默认智能体**：新建项目对话框新增“项目默认智能体”，项目会在 AgentDeck 自己的 `projects.db` 中记住该平台；从项目菜单新建会话时优先使用它。
- **应用默认智能体**：设置页新增“新建与启动”分类，可设置默认智能体，初始为 Claude Code CLI。新建项目时可勾选“同时设为应用默认智能体”。
- **智能体右键菜单**：智能体列表项右键（或 `Shift + F10`）提供“新建会话…”与“新建项目…”，并预选该智能体。不可启动的来源（如桌面客户端、网关、导入记录）两项置灰并说明原因。
- **新建会话对话框**（`NewSessionDialog`）：可取任意已存在目录启动所选智能体；从项目进入时目录固定为该项目的目录，仍可临时改平台。
- **项目显示名称编辑弹窗**：取代原先挤在侧栏底部的输入框，具备保存 / 取消、错误就地保留草稿、IME 回车保护，并明确说明不会重命名磁盘目录。

## Changed

- **项目列表改为单行显示**：每项只保留文件夹图标、项目名称和会话数量，完整路径、会话与收藏数量、默认智能体通过悬停提示查看。配色改用 `--ad-*` 主题变量（悬停 `--ad-hover`、选中 `--ad-selected`），与主窗体其他导航项一致，深浅色同步。
- **移除项目的措辞与行为**：菜单项改为“从项目列表移除…”，确认弹窗说明会清除显示名称与默认智能体，但保留目录、文件和会话；若目录中已有会话，项目仍会按目录名称显示。
- 项目区标题栏显示项目总数，新建入口收为带提示的图标按钮；智能体区高度调整，为项目列表留出更多滚动空间。
- `ProjectView` 增加 `agent` 字段（默认智能体），项目视图与声明清单同步。

## Fixed

- **重复添加已声明目录会静默覆盖原设置**：再次新建并选择同一目录时，此前会覆盖已保存的显示名称和默认智能体。现在直接拒绝并提示改用项目菜单。
- **创建失败会改动既有声明**：目录创建失败时不再回滚式删除既有声明，改为先建目录、成功后再写库。
- **浏览筛选干扰默认智能体**：从项目菜单打开的新建会话不再继承侧栏的智能体筛选。
- **智能体标识与 CLI 命令混用**：新增固定映射（`qoder → qodercli`、`qoder-cn → qoderclicn`、`cursor / cursor-agent → cursor-agent`），拒绝把任意输入当命令执行。
- **特殊字符路径**：切换目录改用 `Set-Location -LiteralPath … -ErrorAction Stop`，含方括号或单引号的目录不再被当作通配符，切目录失败也不会在错误目录启动 CLI。
- **默认智能体的统计口径**：会话数统计排除只读、保留、WSL、网关与导入来源，避免选中无法启动的平台；无可用记录时回退 `claude`。
- 声明清单写入前校验路径控制字符；项目显示名称校验控制字符、空白与 200 字符上限。
- 偏好设置合并改用最新状态，创建项目期间改动的其他设置不再被覆盖。
- 侧栏智能体 / 项目请求增加卸载保护，旧响应不会覆盖新状态。

## Known Issues

- 新建会话只是打开终端并请求启动 CLI，产生会话记录后需要刷新列表才能看到，尚未自动刷新。
- 项目显示名称只影响 AgentDeck 项目列表，会话列表里的项目字段仍按目录名归组。
- 深色模式沿用主题变量改动，本次未单独做视觉走查。
