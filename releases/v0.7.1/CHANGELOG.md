# AgentDeck v0.7.1

发布日期：2026-10-20

在 v0.7.0 之上新增「自适应」阅读宽度并设为默认，设置新增「工作台」分类，补齐会话列表快捷键与右键
菜单提示，整理若干界面细节，并修复全文索引在应用运行中 WAL 文件滞留的问题。

## Added

- **阅读宽度新增「自适应」档**：消息列取阅读区的约 80%，封顶 1400px，且不窄于「适中」档的 820px、
  不超过阅读区本身（`min(100%, max(820px, min(80%, 1400px)))`）。代码块与表格在消息列内，随之放宽。
  本机最大化（2560 px 宽）时阅读区约 1784px，消息列由 820px 放宽到约 1400px。
- **设置新增「工作台」分类**：侧栏默认状态（展开 / 收起，窗口窄于 900px 时仍始终收起）、侧栏宽度
  （「恢复自动宽度」）、会话详情栏默认状态、会话列表默认排序、隐藏没有会话的项目。更改立即生效，之后
  手动开合不受影响。侧栏里的「隐藏空项目」眼睛图标与该设置共用同一份偏好。
- **「新建与启动」新增「最近使用的目录」**：显示已记录个数，「清除记录」只清这份记录，不影响目录与会话。
- **会话列表快捷键**：选中行按 F2 重命名；按 Delete 进入删除预览与确认，与右键菜单、批量条的「删除会话…」
  是同一入口、同一目标口径（行在多选里则作用于整组），来源不支持删除时不响应。快捷键表同步补充 F2、
  Delete 与菜单键。
- **隐藏空项目开关**：项目标题旁的眼睛图标；隐藏后显示「130/132」，悬停说明被隐藏的个数，正在用作筛选的
  项目始终显示。

## Changed

- **阅读宽度默认值改为「自适应」**：只对没有存过这项设置的用户生效；已存过「适中」或「宽版」的保持原选择。
  存了无效值时回退到自适应。
- **右键菜单**：「打开会话」「重命名」「删除会话…」显示 Enter / F2 / Del 提示；灰掉的「在终端中继续会话」
  「复制恢复命令」「导出」「复制工作目录」在悬停时说明原因；删除项在可用时用红色。
- **阅读定位条**改为「第 N–M 段，共 T 段」，悬停说明「段」是消息、思考、工具调用与结果各算一段。
- **载入大会话**时显示「正在载入会话（约 N 条消息）…」，不再只有一个转圈。
- **详情栏**去掉与顶部图标、底部栏重复的「导出为 Markdown」，只留「归档」「删除会话…」。
- **「新建会话」**改为主色按钮；选中行左侧竖条由 2px 加粗到 3px；状态栏写作「来源：本地文件」。
- **侧栏智能体区**封顶 45% 高度、按内容撑开：12 个智能体在 800px 高的窗口里不再多出一条滚动条，更多
  时只在该区内滚动，项目区至少留 140px，窗口过矮时整个侧栏滚动。
- **设置页用语统一**：标题栏「偏好设置」改为「设置」；「新建与启动」换成不与「应用设置」重复的图标；
  「Agent」统一为「智能体」；「导航宽度」统一为「侧栏宽度」；「默认智能体」说明不再写死「Claude Code
  CLI」；设置内容区固定滚动条槽位，切换分类时不再左右抖动。

## Improved

- **索引 WAL 不再滞留**：每趟索引构建结束后执行一次 `wal_checkpoint(TRUNCATE)`。此前一趟构建里最大的
  会话决定 WAL 的高水位，提交后文件只增不缩，本机实测扫描结束后停在 156 MB，关闭前见过 387 MB，干净退出
  才释放。修复后本机同一场景峰值 63 MB、扫描结束即回到 0。
- **增量重读跳过没变的段落**：`Index.Add` 比较已存正文，一致就跳过 FTS 删除与插入；变了的段落仍整段替换，
  旧词不再命中、新词命中。本机真实数据上，启动扫描的 WAL 峰值由 63 MB 降到 0.1 MB（两次测量的数据状态
  可能略有不同，数字只说明方向）。
- 实测过的非热点（未改动）：本机 691 条会话列表首次约 1.0 秒、之后约 0.45 秒；体积最大的 79 MB 会话解析
  约 137 ms，序列化 39 MB 约 45 ms，哈希约 18 ms。

## Known Issues

- 迁移完成后、重启之前的写入仍落在旧位置（同 v0.7.0）；数据位置变更只在重启后生效。
- 阅读宽度默认值只对没存过该设置的用户生效：已存过「适中」的用户需要在「设置 → 外观」里自行改选。
- 窗口很矮时右键菜单底部的「删除会话…」会被窗口下沿裁掉一部分，需要滚动菜单（Fluent 在放不下时的默认
  处理，本版未改动）。
- 侧栏智能体区「超过 45% 后在区内滚动」按样式逻辑实现，本机只有 12 个智能体，该分支未实测。
- 读取上游不在原目录、只存在于永久库的会话时，启动扫描仍会对它们解压并重新分词；本版未量化其耗时。
- 索引库运行中仍会出现短暂的 WAL，扫描结束后截断；检索正读着时截不掉，下一趟再截。

## 未执行

- **自适应阅读宽度在最终构建上的最大化列宽核对未执行**：最大化截图时消息列约 820px（当时本机偏好是
  「适中」），之后设置页显示为「自适应」，但没有再最大化量一次列宽；宽度由公式与 `readerWidthCss` 单测
  确认，未量 DOM。
- **红色删除项**未见到可用状态：核对时右键的会话（DeepSeek Harness）不支持删除，该项是灰色。
- **F2 / Delete 快捷键**未实际按键验证（点击脚本不发键盘事件）；其与右键菜单、批量条共用同一入口由代码
  审阅确认。
- **「工作台」分类里各设置项的实际切换未执行**：下拉框是系统原生控件，点击脚本点不开，没有逐项验证
  「改了立即生效」；偏好的解析与回退由单测覆盖。
- **窗口很矮时的侧栏整体滚动**、**隐藏空项目偏好重启后是否保持**未实测。
- 设置页其余未改动区域（迁移弹窗、备份恢复等）本版未重新走查。
