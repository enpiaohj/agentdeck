# AgentDeck v0.20.5

发布日期：2026-11-18

## Fixed

- 界面和提示里有 5 处写的“设置 > …”路径指向不存在的设置页面，用户照着找不到，现已指向实际存在的页面：
  - 会话列表空状态里的“设置 > 数据来源”改为“设置 > 诊断”（检查智能体是否被检测到）；
  - 检测到上次未正常退出时提示的“设置 > 数据与诊断”改为“设置 > 诊断”（重建索引）；
  - 数据位置不可用时提示的“设置 > 数据与诊断”改为“设置 > 数据管理”（改回默认位置）；
  - 找不到 PowerShell 7 时提示的“设置 > 新建与启动”改为“设置 > 终端”；
  - 删除对话框里的“设置 › 会话”改为“设置”>“会话”（分隔符与其他处一致）。
- 会话列表空状态里“请单击‘刷新’”改为与按钮实际名称一致的“刷新会话列表”；“若仍未看到新会话，请按 F5 或点…”改为“若仍未显示新会话，请按 F5 或选择…”。

## Changed

- 继续按微软中文术语与风格统一其余界面文字（共 60 处、21 个文件）：
  - 用词：“载入”改为“加载”，“清空选择”改为“清除选择”，“面板”改为“窗格”，“工作空间”改为“工作区”，“折叠导航”改为“收起导航”，“确认窗口”改为“确认对话框”。
  - 英文“Agent”统一为“智能体”（含“子智能体”和“跨智能体的历史会话搜索与恢复工作台”）。
  - “读取中… / 保存中… / 创建中… / 启动中… / 查找中… / 处理中…”统一为“正在读取… / 正在保存… / 正在创建… / 正在启动… / 正在查找… / 正在处理…”。
  - 口语改为书面表达：“每天最多打扰一次”改为“每天最多提示一次”，“子会话收在主会话下”改为“子会话归入主会话”，“还没结束”改为“尚未结束”，“保持原样”改为“保持不变”，“不能用 CLI 恢复命令继续”改为“无法使用 CLI 恢复命令继续”，“尝试使用”改为“请尝试使用”，“本机文件仍在”改为“本机文件仍然存在”。
  - “舒适适合长文阅读”等容易读成叠字的说明，给选项名加了引号。
- README 里的“一键”“悄悄”“装在”同步修改。

## 说明

- 本版只有上面的文字调整，没有改动功能、数据格式或配置字段。按版本规范（`0.x.y` 只用于修复缺陷）它本应是 v0.21.0；这里按维护者的指定使用 v0.20.5。
- 检查后决定不改的：“Token 消耗”（大模型领域通用叫法）、“上游”（项目术语，改动面大）、“原生恢复”“复制恢复命令”里表示“继续会话”的“恢复”、“置顶 / 归档 / 侧栏 / 目录”。

## Known Issues

- **构建工具链有一项尚无修复版本的高危公告（与 v0.20.1 至 v0.20.4 相同的例外，沿用维护者的确认）**：`npm audit` 报告 `picomatch`（`<=4.0.7`，ReDoS，GHSA-fc5q-39xc-vjpf）经 `vite` → `fdir` / `tinyglobby` 传导，共 4 项高危。发布时重新核对：npm 上 `picomatch` 的最新版本仍是 4.0.7，没有修复版本；npm 建议的把 `vite` 降到 6.2.7 本身带有另一个高危公告，不能消除问题。影响范围：只有开发时的前端构建工具（`devDependencies`），不是运行时依赖；`npm audit --omit=dev`（生产依赖）为 0 项；发布的 exe 和前端产物里都不含 `picomatch`。上游一发布修复版本就升级。
- “标签”一词同时指会话标签和终端标签页，存在歧义（微软会区分为“标签”和“选项卡”），未改。
- 重建的会话不是原文件：工具调用的 id 配对、思考内容、消息 id 无法还原；只支持 Claude Code。
- 与 v0.20.0 相同：会话保留期的“到期”按文件修改时间和默认 30 天估算；原始会话里已经变成 `�` 的内容无法恢复；仅 Windows。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 本版只改界面文字，不改数据库结构与配置字段，首次启动无需迁移。
- 升级：在应用内“检查更新”，或用新 exe 手动替换。
- 回退：换回上一版 exe 即可，数据与配置不受影响。
