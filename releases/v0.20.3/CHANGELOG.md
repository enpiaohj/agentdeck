# AgentDeck v0.20.3

发布日期：2026-11-18

## Changed

- “偏好设置”统一改为微软对应的“首选项”：
  - 设置页左下角“首选项仅应用于当前设备”；
  - 页脚的“首选项”区域与“还原首选项…”按钮，以及确认对话框“还原首选项？”；
  - 备份说明里的“界面首选项”；关于页与 README 里的“标注与首选项”；README 里的“窗口关闭首选项”；
  - 备份相关的两条错误提示（“界面首选项超过 64 KiB”“界面首选项必须是 JSON 对象”）。
- README 里“并记住偏好”改为“并记住该设置”，因为“记住首选项”读起来不通顺。
- 设置搜索里保留了“偏好设置”关键词，搜它仍能找到对应设置。
- 保持不变：历史版本的 CHANGELOG 条目（已发布内容不改写）。

## 说明

- 本版只有上面的文字调整，没有改动功能、数据格式或配置字段，也没有修复缺陷。按版本规范（`0.x.y` 只用于修复缺陷）它本应是 v0.21.0；这里按维护者的指定使用 v0.20.3。

## Known Issues

- **构建工具链有一项尚无修复版本的高危公告（与 v0.20.1、v0.20.2 相同的例外，沿用维护者的确认）**：`npm audit` 报告 `picomatch`（`<=4.0.7`，ReDoS，GHSA-fc5q-39xc-vjpf）经 `vite` → `fdir` / `tinyglobby` 传导，共 4 项高危。发布时重新核对：npm 上 `picomatch` 的最新版本仍是 4.0.7，没有修复版本；npm 建议的把 `vite` 降到 6.2.7 本身带有另一个高危公告，不能消除问题。影响范围：只有开发时的前端构建工具（`devDependencies`），不是运行时依赖；`npm audit --omit=dev`（生产依赖）为 0 项；发布的 exe 和前端产物里都不含 `picomatch`。上游一发布修复版本就升级。
- 重置首选项对话框里的确认按钮仍是“还原默认”（微软常见写法是“还原默认设置”），未改。
- 重建的会话不是原文件：工具调用的 id 配对、思考内容、消息 id 无法还原；只支持 Claude Code。
- 与 v0.20.0 相同：会话保留期的“到期”按文件修改时间和默认 30 天估算；原始会话里已经变成 `�` 的内容无法恢复；仅 Windows。
- 未在 macOS / Linux 上构建运行。

## 升级与回退

- 本版只改界面文字，不改数据库结构与配置字段，首次启动无需迁移。
- 升级：在应用内“检查更新”，或用新 exe 手动替换。
- 回退：换回上一版 exe 即可，数据与配置不受影响。
